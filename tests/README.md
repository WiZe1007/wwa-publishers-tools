# Тести

Запуск усіх тестів:

```bash
npm test
```

Окремий файл:

```bash
node --test tests/unit.test.js
```

Залежностей немає — використовується вбудований тест-раннер Node (потрібен Node 18+).

## Що покрито

| Файл | Що перевіряє |
|---|---|
| `unit.test.js` | Аналіз переспаму: нормалізація форм слів (tap/taps/tapping/tapped → одне слово), поріг щільності 2.5% як в ASOMobile, стоп-слова, дефіси. Цілісність стилів опису та обсягів |
| `api.test.js` | HTTP: всі сторінки та статика віддаються, `/api/health`, `/api/spam-check`, валідація `/api/aso` і `/api/fix-spam`, 404 |
| `site.test.js` | Синтаксис усіх JS-модулів та інлайнових скриптів, існування всіх файлів за посиланнями, синхронність карток стилів у UI з інструкціями на сервері, критичні елементи форми, шаблон How to Publish, розміри icon/banner, відсутність API-ключа в коді |
| `tools.test.js` | Байтова логіка на реальному коді модулів: очищення метаданих MP4 (затирання udta, обнулення дат, незмінність розміру та відеоданих), кодек BMP (заголовок, порядок BGR, накладання прозорості), заповнення шаблону How to Publish |

## Чого не покрито

Обробка зображень через `canvas` (resize, convert, merge, стиснення скріншотів) потребує справжнього браузера — у тестовому середовищі Chromium недоступний. Ці сценарії перевіряються вручну.

Виклики Claude API не тестуються автоматично, щоб не витрачати кредити; перевіряється лише валідація вводу та шляхи без звернення до AI.
